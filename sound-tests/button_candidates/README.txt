# Button sound candidates

Generated short WAV candidates for Gripe Verde button feedback.
They are not wired into the mod yet; open this folder and audition them.

Suggested starting points:
- 01_paper_tick_soft.wav: very neutral
- 03_brass_latch_clean.wav: mechanical, slightly Victorian
- 05_cabinet_snap_soft.wav: cabinet/button feel
- 07_clock_pin_click.wav: pocket-watch style

Pick the number/name you prefer and it can be wired into the UI afterwards.
