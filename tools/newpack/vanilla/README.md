# vanilla/ — Texturas vanilla 1.20.1 (base de construccion)

Las 20 texturas de contenedores de Minecraft 1.20.1, extraidas del mirror
oficial https://github.com/InventivetalentDev/minecraft-assets (rama 1.20.1).

Son la base de construccion del pipeline: el kit parte de estos PNG y
preserva alfa, posiciones de slots e iconos byte a byte (verify.py lo
audita). No se editan a mano.

Uso con vanilla externa: NC_VANILLA=/ruta/ python3 build_*.py
